# TaskFlow 2.0

A simple and user-friendly task management application designed to help people organize their daily work and stay productive.

## Features

- Add new tasks
- Edit and delete tasks
- Set task priorities: Low, Medium, and High
- Add due dates
- Organize tasks into Personal, Work, and Study categories
- Mark tasks as completed
- Search and filter tasks
- Track productivity with a progress bar
- Save tasks in the browser using local storage
- Get daily task suggestions

## How to Use

1. Open the TaskFlow application.
2. Enter a task name.
3. Select its category, priority, and due date.
4. Click the Add Task button.
5. Edit, complete, or delete tasks as needed.

## Technology Used

- HTML
- CSS
- JavaScript
- Browser Local Storage
